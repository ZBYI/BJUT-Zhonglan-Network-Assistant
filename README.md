# 北工大中蓝公寓校园网助手

**中蓝公寓专用。** 专为 **北京工业大学中蓝公寓** 编写的 Windows 一键 Wi-Fi 切换与校园网 Portal 认证脚本。当前主分支为 **v3.2.0 EXTREME**。

> [!IMPORTANT]
> 本工具当前只针对中蓝公寓中名称符合以下规则的校园 Wi-Fi：
>
> **`CMCC-BJUT-SUSHE-H数字-5G`**
>
> 例如：`CMCC-BJUT-SUSHE-H1021-5G`。  
> 不带 `-5G` 的网络、其他宿舍网络、手机热点和其他普通 Wi-Fi 都不会参与自动择优。

> [!IMPORTANT]
> **首次使用必须先填写自己的校园网账号和密码。**
>
> - BAT 第 **11 行**：校园网账号
> - BAT 第 **12 行**：校园网密码
> - 账号末尾的 **`@campus` 必须保留**

---

## 快速开始

1. 下载 `BJUT-Network-Assistant.bat`。
2. 右键 BAT → **编辑**。Windows 11 如未直接显示“编辑”，可选择“显示更多选项”，也可以使用记事本或 VS Code。
3. 修改第 **11 行**：

```bat
set "BJUT_ACCOUNT=YOUR_ACCOUNT@campus"
```

只替换 `YOUR_ACCOUNT`，例如：

```bat
set "BJUT_ACCOUNT=你的账号@campus"
```

4. 修改第 **12 行**：

```bat
set "BJUT_PASSWORD=YOUR_PASSWORD"
```

只替换 `YOUR_PASSWORD`。

5. 保存后双击 BAT 即可。

> [!WARNING]
> 请不要删除账号末尾的 **`@campus`**，正确格式始终是 `你的账号@campus`。

### 可选：开机后自动运行

如果希望每次登录 Windows 后自动连接中蓝公寓校园网，可以把 BAT 的**快捷方式**放进 Windows 启动文件夹：

1. 按 **`Win + R`**。
2. 输入：

```text
shell:startup
```

3. 回车打开“启动”文件夹。
4. 为 `BJUT-Network-Assistant.bat` 创建一个快捷方式，并把**快捷方式**放进该文件夹。
5. 以后每次登录 Windows，脚本都会自动运行一次；连接和认证成功后会自动关闭窗口。

> [!NOTE]
> 建议把 BAT 本体放在一个固定位置，只把快捷方式放入启动文件夹。之后如果移动 BAT，本来的快捷方式可能失效。  
> 如果极少数情况下 Windows 刚登录时无线网卡尚未准备好，脚本可能提示失败；此时手动再运行一次即可。

## v3.2.0 EXTREME 的主要特点

- **专门适配中蓝公寓**：只识别并比较 `CMCC-BJUT-SUSHE-H数字-5G`。
- **自动选择最强目标 Wi-Fi**：同名 SSID 存在多个 BSSID 时取最高信号，再在目标 SSID 之间择优。
- **自动切换网络**：当前连接不是目标校园 Wi-Fi 时，脚本会主动断开并连接最强目标网络。
- **首次连接也能自动处理**：Windows 没有保存对应 WLAN Profile 时会自动创建。
- **自动完成 Portal 登录**：获取 IPv4 后直接提交认证，并解析服务器返回的 `result` 和 `msg`。
- **极限缩短等待时间**：主流程只启动一个 PowerShell 进程，Wi-Fi 和 IPv4 状态满足条件后立即继续。
- **通常不用管代理 / VPN / “梯子”软件**：Portal 请求和 Internet 探测不使用系统 HTTP 代理，**大多数情况下不需要为了运行本工具专门关闭此类软件**。
- **成功后自动关闭窗口**：确认联网后自动退出，不需要手动关窗口。
- **失败时保留窗口**：方便直接查看 Wi-Fi、IPv4、Portal 或账号相关提示。
- **不常驻后台**：双击运行一次，完成后即退出，不建立持续监控任务。

> [!NOTE]
> 少数 VPN / TUN 软件如果强制接管默认路由、DNS，或禁止访问局域网，仍可能影响校园网认证。只有在反复失败时，才建议临时关闭相关软件排查。

## 失败时先看这里

如果脚本运行失败，建议按这个顺序处理：

1. **先直接重新双击运行一次脚本。** 无线扫描、DHCP 或 Portal 偶发超时时，重新运行往往即可恢复。
2. 检查账号和密码是否填写正确，并确认账号末尾仍保留 **`@campus`**。
3. 检查校园网账号是否存在 **余额不足、欠费、停机、到期或其他账户状态异常**。账号本身无法正常认证时，脚本也无法完成登录。
4. 确认当前位置能够搜索到名称符合 `CMCC-BJUT-SUSHE-H数字-5G` 的中蓝公寓校园 Wi-Fi。
5. 如果重复失败且正在使用 VPN / TUN / 代理软件，再临时关闭相关软件后重试，用于排除路由、DNS 或局域网访问被接管的问题。

## 脚本实际会做什么

```text
双击 BAT
  ↓
读取当前 Wi-Fi
  ↓
当前是否已连接中蓝公寓目标 Wi-Fi
  ├─ 是 → 保持当前连接
  └─ 否 → 立即断开当前 Wi-Fi
  ↓
扫描附近 Wi-Fi
  ↓
只保留 CMCC-BJUT-SUSHE-H数字-5G
  ↓
选择信号最强的目标 SSID
  ↓
必要时自动创建 WLAN Profile
  ↓
连接目标 Wi-Fi
  ↓
IPv4 一出现立即继续
  ↓
快速检查是否已经联网
  ├─ 已联网 → 自动关闭
  └─ 未联网 → 提交 Portal 认证
                   ↓
             读取 Portal 返回结果
                   ↓
             快速验证 Internet
                   ↓
                自动关闭
```

如果脚本启动时原本连接的是其他 Wi-Fi，而附近最终没有找到目标中蓝公寓 Wi-Fi，脚本会尝试重新连接原来的 Wi-Fi，尽量避免误运行后一直处于断网状态。

## 目标 Wi-Fi 识别规则

脚本只接受：

```text
CMCC-BJUT-SUSHE-H数字-5G
```

会参与选择，例如：

```text
CMCC-BJUT-SUSHE-H0921-5G
CMCC-BJUT-SUSHE-H1021-5G
CMCC-BJUT-SUSHE-H1023-5G
```

不会参与选择，例如：

```text
CMCC-BJUT-SUSHE-H1021
手机热点
家用 Wi-Fi
其他运营商 Wi-Fi
```

因此，即使其他 Wi-Fi 信号更强，只要名称不符合目标规则，也不会影响脚本选择。

## 为什么 v3.2 很快

v3.2 相比早期版本主要做了这些优化：

- 主流程只启动 **一个 PowerShell 进程**；
- Wi-Fi 连接状态约每 **120 ms** 检查一次；
- IPv4 状态约每 **100 ms** 检查一次；
- 删除大部分固定等待；
- Internet 预检测采用短超时；
- Portal 请求返回后直接解析认证结果；
- 条件一满足就立即进入下一步，而不是固定等待若干秒。

脚本的速度上限仍会受到无线扫描、AP 关联、DHCP 和校园网 Portal 响应速度影响。

## 常见问题

### 脚本显示成功，但 Windows 右下角仍显示“无 Internet”

Windows 网络状态图标和实际联网状态有时不会同步刷新。

如果脚本已经显示：

```text
[成功] 校园网认证成功，网络已连接
```

或者：

```text
[认证] Portal 已返回认证成功
```

但任务栏暂时仍显示“无 Internet”“正在识别网络”或旧状态，可以直接打开网页测试。网页能够正常访问时，说明实际网络已经可用，Windows 图标通常稍后会自行刷新。

### 为什么成功后窗口会自己关闭？

这是 v3.2 的设计。确认联网后，脚本会自动结束并关闭窗口；如果失败，则保留窗口和错误提示，方便排查。

### 为什么已经连着校园 Wi-Fi 还要扫描？

因为附近可能存在信号更强的目标中蓝公寓 Wi-Fi。如果当前网络已经是最强目标网络，脚本不会重复切换。

### 第一次连接某个目标 Wi-Fi 为什么也能自动完成？

中蓝公寓目标 WLAN 为开放网络。若 Windows 尚未保存相应配置，脚本会自动创建 WLAN Profile，再发起连接。

### 出现中文乱码或 “is not recognized” 怎么办？

如果你自己重新保存过 BAT，请确认文件格式为：

```text
UTF-8 无 BOM
CRLF
```

不要保存为 UTF-8 with BOM，也尽量不要使用 LF-only 换行。

## 隐私与数据说明

- 本项目不包含作者自建服务器、云端后台、数据库、广告 SDK、遥测或统计服务。
- 校园网账号、密码和 IPv4 不会上传给本项目作者或 GitHub。
