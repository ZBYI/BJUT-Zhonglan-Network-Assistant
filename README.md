# 北工大校园网助手

一个面向北京工业大学校园网的 Windows 一键连接与认证脚本。当前主分支为 **v3.2.0 EXTREME**。

> [!IMPORTANT]
> **首次使用必须先修改账号和密码。**  
> v3.2.0 中：
> - **第 11 行：校园网账号**
> - **第 12 行：校园网密码**
>
> 账号末尾的 **`@campus` 必须保留，不要删除。**

## 下载后怎么改

1. 下载 `BJUT-Network-Assistant.bat`。
2. 找到 BAT 文件，**右键 → 编辑**。  
   Windows 11 如果没有直接看到“编辑”，可点“显示更多选项 → 编辑”，也可以用记事本或 VS Code 打开。
3. 找到第 **11 行**：

```bat
set "BJUT_ACCOUNT=YOUR_ACCOUNT@campus"
```

只把 `YOUR_ACCOUNT` 替换成你的校园网账号。

正确示例：

```bat
set "BJUT_ACCOUNT=你的账号@campus"
```

4. 找到第 **12 行**：

```bat
set "BJUT_PASSWORD=YOUR_PASSWORD"
```

只把 `YOUR_PASSWORD` 替换成你的校园网密码。

5. 保存后双击 BAT。

> [!WARNING]
> **不要删除 `@campus`。**  
> 正确格式始终是：**`你的账号@campus`**。

> [!NOTE]
> 如果你自己重新保存 BAT，建议使用 **UTF-8 无 BOM + CRLF**。  
> 这样可以避免 CMD 对 UTF-8 中文和 LF 换行处理不稳定导致的乱码或“某段中文被当成命令执行”。

## v3.2.0 EXTREME：现在做什么

v3.2 的目标很简单：

> **双击一次，以尽可能短的时间切到中蓝校区最强的目标 5G 校园 Wi-Fi，并完成 Portal 认证。**

当前自动识别的目标 Wi-Fi 格式是：

**`CMCC-BJUT-SUSHE-H数字-5G`**

例如：

```text
CMCC-BJUT-SUSHE-H0921-5G
CMCC-BJUT-SUSHE-H1021-5G
CMCC-BJUT-SUSHE-H1023-5G
```

### 运行流程

```text
双击 BAT
  ↓
读取当前 Wi-Fi
  ↓
当前 Wi-Fi 是否为中蓝目标 5G 网络
  ├─ 是 → 不主动断开
  └─ 否 → 立即断开当前 Wi-Fi
  ↓
扫描附近中蓝 5G 校园 Wi-Fi
  ↓
仅保留 CMCC-BJUT-SUSHE-H数字-5G
  ↓
选择信号最强的一个
  ↓
必要时自动创建 WLAN 配置
  ↓
自动连接
  ↓
IPv4 一出现立即继续
  ↓
快速检查是否已经联网
  ├─ 已联网 → 立即结束
  └─ 未联网 → Portal 登录
                   ↓
             直接读取 Portal 返回结果
                   ↓
             快速验证 Internet
                   ↓
                  结束
```

### 为什么 v3.2 比 v3.0 / v3.1 更快

v3.2 不再反复启动多个 PowerShell 进程，而是：

- **只启动一个 PowerShell 进程完成整个主要流程**；
- Wi-Fi 连接状态约每 **120 ms** 检查一次；
- IPv4 约每 **100 ms** 检查一次；
- 去掉大量固定等待时间；
- Internet 预检测采用短超时；
- Portal 请求提交后**直接解析服务器返回的 `result` 和 `msg`**；
- Portal 一旦明确成功，就立刻进入联网验证；
- 成功后只短暂停留窗口。

因此脚本不是“固定等几秒再继续”，而是：

> **条件一满足就立即进入下一步。**

### 其他使用特点

- **成功后自动关闭窗口**：检测到已经联网，或 Portal 认证成功并验证 Internet 后，窗口会自动结束，不需要手动关闭。
- **失败时保留窗口并给出提示**：方便查看是 Wi-Fi、IPv4、Portal 还是账号侧的问题。
- **通常不需要专门关闭代理 / VPN / “梯子”软件**：脚本的 Portal 请求和 Internet 探测不使用系统 HTTP 代理，并会自行处理目标 Wi-Fi 的切换。
- 如果某些 VPN / TUN 软件强制接管默认路由、DNS 或禁止访问局域网，仍可能影响校园网认证；这类情况下可临时关闭相关软件后再试。

## 关于“中蓝”和“5G”

> [!IMPORTANT]
> 自动择优范围不是所有 Wi-Fi，而是**只在中蓝校区符合命名规则的 5G 校园 Wi-Fi 中比较信号强度**。

会参与选择：

```text
CMCC-BJUT-SUSHE-H0921-5G
CMCC-BJUT-SUSHE-H1022-5G
CMCC-BJUT-SUSHE-H1023-5G
```

不会参与选择：

```text
CMCC-BJUT-SUSHE-H1021
手机热点
家用 Wi-Fi
其他运营商 Wi-Fi
```

所以即使手机热点信号是 100%，只要它不符合规则，也不会影响校园 Wi-Fi 的选择。

## 脚本成功，但 Windows 还显示“没网”？

> [!NOTE]
> **这是可能出现的正常现象。Windows 网络状态界面和实际 Internet 连通状态并不总是同步刷新。**

如果脚本已经显示类似：

```text
[成功] 校园网认证成功，网络已连接
```

或者：

```text
[认证] Portal 已返回认证成功
```

但 Windows 右下角仍暂时显示：

- 无 Internet
- 正在识别网络
- 旧的 Wi-Fi 状态
- 网络图标没有立即变化

不一定代表认证失败。

判断方式：

1. 优先看脚本自己的 Portal 和 Internet 检测结果；
2. 直接打开浏览器访问网页；
3. 如果网页能正常加载，说明实际网络已经可用；
4. Windows 图标通常稍后会自行刷新。

## 找不到目标 Wi-Fi 时

如果脚本启动时连接的是其他 Wi-Fi，v3.2 会先断开它。

如果随后附近没有找到：

```text
CMCC-BJUT-SUSHE-H数字-5G
```

脚本会尝试重新连接刚才的原 Wi-Fi，尽量避免因为误点 BAT 而一直保持断网。

- 不负责切换 Wi-Fi；
- 已连接校园网络后自动获取 IPv4 并完成 Portal 认证。

## 常见问题

### 脚本运行失败怎么办？

建议按下面顺序排查：

1. **直接重新双击运行一次脚本**。无线扫描、DHCP 或 Portal 偶发超时，第二次通常可以直接恢复。
2. 确认账号和密码填写正确，并且账号末尾仍保留 **`@campus`**。
3. 检查校园网账号是否存在**欠费、停机、到期或其他账户状态异常**。如果账号本身无法正常认证，脚本也无法绕过校园网账户限制。
4. 确认当前位置确实能搜索到符合规则的中蓝 5G 校园 Wi-Fi。
5. 如果正在使用 VPN / TUN / 代理软件且重复失败，可临时关闭后再试，用于排除其对默认路由、DNS 或局域网访问的影响。

> [!NOTE]
> 多数情况下，使用本工具时**不需要特意关闭代理、VPN 或“梯子”软件**。脚本的 Portal 请求与联网探测不使用系统 HTTP 代理；只有少数会强制接管网络路由或禁止局域网访问的软件可能造成干扰。

### 为什么成功后窗口自己关了？

这是 v3.2 的设计。  
一旦确认已经联网，脚本会自动关闭窗口，避免每次认证成功后还需要手动退出。失败时则会保留窗口并显示提示，便于排查。

### BAT 出现中文乱码或提示“is not recognized”

优先确认文件格式：

```text
UTF-8 无 BOM
CRLF
```

不要使用 UTF-8 BOM，也尽量不要把 BAT 保存为 LF-only。

### 为什么没有选择附近最强的任意 Wi-Fi？

这是设计行为。脚本只比较：

**`CMCC-BJUT-SUSHE-H数字-5G`**

其他网络根本不会进入候选列表。

### 当前已经连接校园 Wi-Fi，为什么还要扫描？

因为附近可能存在另一个信号更强的目标校园 Wi-Fi。如果当前已经是最强目标网络，则不会重复切换。

### 第一次连接某个校园 Wi-Fi 为什么会创建配置？

目标网络本身是开放 WLAN。如果 Windows 尚未保存对应配置，脚本会自动创建 WLAN Profile 后再连接。

## 注意事项

- **不要把填写真实账号和密码的 BAT 上传到 GitHub、网盘、聊天群或发送给他人。**
- 仓库公开版本仅保留 `YOUR_ACCOUNT@campus` 与 `YOUR_PASSWORD` 占位符。
- 当前 Portal 地址为 `http://10.21.221.98:801/eportal/portal/login`，学校后续调整认证系统时脚本可能需要同步更新。
- v3.2 当前 Wi-Fi 自动选择规则针对**中蓝校区**的 **`CMCC-BJUT-SUSHE-H数字-5G`**。
- 使用者应仅使用本人有权使用的校园网账号与网络。

## 隐私与数据说明

- 本项目不包含作者自建服务器、云端后台、数据库、广告 SDK、遥测或统计服务。
- 校园网账号、密码和 IPv4 不会上传给本项目作者或 GitHub。
- 账号和密码仅保存在用户自己的本地 BAT 文件中。
- Portal 认证时，账号、密码和 IPv4 会按照校园网现有认证协议发送至配置的校园网认证服务器，这是完成登录所必需的请求。
- 脚本会访问公开网页资源测试 Internet 连通性，但不会主动附带校园网账号或密码。
- 脚本不会常驻后台，也不会建立用户行为记录数据库。
- 当前 Portal 接口使用 HTTP，其传输安全性取决于校园网自身的网络环境与认证机制。
